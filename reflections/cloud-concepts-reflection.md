# Cloud Computing Concepts Reflection

Cloud computing has become an essential part of my daily life, even before I fully understood its concepts in class.
Many of the applications I use every day rely on cloud technology to provide reliable, fast, and accessible services over the internet.

One cloud service I regularly use is **Google Drive**. It is classified as **Software as a Service (SaaS)** because it allows users to store,
manage, and share files through a web browser without installing or maintaining the underlying infrastructure. It uses a **Public Cloud**
deployment model because it is available to anyone with a Google account.

Another service I frequently use is **Facebook Messenger**. It is also a **SaaS** application since it provides instant messaging, voice calls,
and file sharing through cloud-based servers. Messenger operates on a **Public Cloud** because millions of users access the same cloud infrastructure
while keeping their personal data separate through account security.

The third cloud service I use is **Canva**. Canva is a **SaaS** platform because it allows users to create graphics and presentations directly through
a web browser without installing professional design software. Like the previous services, Canva uses a **Public Cloud** deployment model because it
is available online to users worldwide.

Version control is extremely important in cloud computing because cloud projects often involve multiple developers working on the same files simultaneously.
Without version control, important changes could be lost or overwritten. Git and GitHub make collaboration easier by recording every change made to a project, allowing developers to review previous versions, identify mistakes, and restore files when necessary. GitHub also supports branching and pull requests,
enabling teams to develop new features safely before merging them into the main project. Overall, cloud computing and GitHub complement each other by making
software development more organized, collaborative, and efficient, especially in modern cloud-based environments.
